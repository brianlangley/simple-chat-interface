# simple-chat-interface

A simple chat interface, where users can send a message and get one back.

Built with Vite and TailwindCSS following DRY (Don't Repeat Yourself) and KISS (Keep It Simple, Stupid) principles.

## Features

- Clean, minimal chat interface
- Send messages and receive automated responses
- Responsive design with TailwindCSS
- Fast development with Vite

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open http://localhost:5173 in your browser.

### Build

```bash
npm run build
```

The production-ready files will be in the `dist` directory.

### Preview Production Build

```bash
npm run preview
```

## Project Structure

- `src/chat.js` - Chat functionality
- `src/main.js` - Application initialization
- `src/style.css` - TailwindCSS imports
- `index.html` - HTML entry point
